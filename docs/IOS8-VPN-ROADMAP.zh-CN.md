# IOS8 VPN 客户端中文开发路线图

## 1. 产品原则

- 产品名：IOS8 VPN。
- 平台：Windows 10 / 11 x64、iPhone。
- 默认语言：简体中文。
- 使用场景：个人自建美国 VPS，非商业用途。
- 网络模式：智能分流、全局美国。
- 客户端基于 Hiddify 公开 Fork，网络核心沿用其集成的 sing-box；不从零实现 VPN 协议或系统隧道。

## 2. 首页信息架构

首屏只显示用户日常需要的信息：

- 连接状态：未连接 / 正在连接 / 已连接 / 正在恢复。
- 当前模式：智能分流 / 全局美国。
- 当前节点：IOS8 美国 VPS。
- 一键连接 / 断开。
- 当前出口 IP、延迟、最近检测时间。
- 明确的错误原因与“重新检测”入口。

其他页面：
- 节点：节点名称、协议、延迟、健康状态。
- 规则：智能分流 / 全局模式、规则集版本和更新时间。
- 诊断：DNS、IPv4 / IPv6、隧道握手、出口 IP、最近错误。
- 设置：开机启动、网络切换重连、自动连接、日志导出、关于与许可。

## 3. 两种网络模式

### 智能分流（默认）

- 中国大陆域名和 IP：DIRECT。
- 回环、局域网、私有地址、链路本地地址：DIRECT。
- 其余互联网目标：US 节点。
- DNS 请求遵循同一分流策略，代理域名解析不得意外走本地直连。
- 规则集必须有版本、更新时间和完整性校验。
- IPv6 要么完整纳入同一策略，要么明确禁用隧道外 IPv6；不允许无意绕过。

### 全局美国

- 所有互联网流量通过 US 节点。
- 明确保留必要的本机回环和用户选择的局域网访问。
- DNS 走隧道。
- 切换失败自动恢复此前模式。

## 4. Windows 实现

- 使用上游 Windows TUN / 服务实现，不将旧 Network Control PowerShell Agent 作为数据平面。
- 安装、卸载、升级、开机启动、托盘操作。
- 网络从 Wi-Fi 切换到有线 / 热点时自动重连。
- 系统睡眠唤醒后重新验证隧道和 DNS。
- 智能分流可逐步支持进程 / 应用规则，但必须基于上游现有能力和实际测试。
- 构建 x64 安装包；无 Authenticode 证书时明确提示未签名。

## 5. iPhone 实现

- 使用上游 Packet Tunnel Provider / Network Extension。
- 需要 Apple Developer 账号、Network Extension entitlement、Bundle ID、App Group 和 provisioning profile。
- 优先通过 TestFlight 内测。
- 支持 Wi-Fi / 蜂窝切换、后台恢复和系统 VPN 授权。
- iOS 不提供与 Windows 相同的普通应用级分流能力；首期按域名 / IP 规则集实现，并在 UI 明确平台差异。
- iOS 签名证书和 provisioning profile 只保存在 GitHub Actions Secrets，不进入仓库。

## 6. 与私有 IOS8 VPN Server 的交互

- 服务器生成短时、一次性配对令牌。
- 客户端通过 Universal Link / 自定义深链打开导入流程。
- 令牌兑换后获得设备独立凭据。
- 每台设备可独立撤销；客户端不能使用管理员账号密码连接数据平面。
- 客户端定期获取路由规则、服务器配置和版本信息。
- 客户端上报最小化诊断摘要：版本、平台、模式、隧道状态、延迟、出口 IP、DNS 结果和错误码。

## 7. 安全与隐私

- 不记录用户浏览内容、完整 URL 或 DNS 查询历史。
- 诊断仅收集排障必要的元数据，并提供日志导出前的脱敏。
- 服务端凭据按设备独立发放、可撤销。
- 不把长期密钥放入二维码、URL、剪贴板或普通日志。
- 网络切换必须有健康检查和自动恢复路径。
- UI 清楚说明系统 VPN 权限和路由范围，不宣传静默绕过系统授权。

## 8. 开发里程碑

1. 许可、上游结构与 Windows / iOS 构建环境核验。
2. IOS8 品牌、简体中文首页和基础导航。
3. Windows 全局模式 MVP。
4. Windows 智能分流与断线恢复。
5. iPhone TestFlight 构建和全局模式。
6. iPhone 智能分流、DNS 与网络切换。
7. 与 IOS8 VPN Server 完成临时配对、设备撤销和配置更新。
8. 两个平台分别进行 IPv4 / IPv6 / DNS / MTU / 睡眠唤醒 / Wi-Fi / 蜂窝测试。
9. GitHub Actions 发布候选版本，附 SHA-256 和已知问题。

## 9. 发布前必须通过

- Windows / iPhone 安装、升级、卸载。
- 连接、断开、重连和网络切换。
- 智能分流：国内直连、海外经美国。
- 全局模式：互联网出口为 VPS 公网 IP。
- DNS 不泄漏；IPv6 不绕过策略。
- 断线后能自动恢复本地网络。
- 临时令牌过期、重复兑换和设备撤销均有效。
- 上游许可、第三方依赖许可与签名流程复核。
